# 岩山の城 | 3Dビューア

岩山の上に立つ城を、Three.jsで3D表示するサイトです。GitHub Pagesで公開しています。

## 操作

- ドラッグ／スワイプ（1本指）：視点を回転（横だけでなく、真上から見下ろすこともできます）
- ピンチ／ホイール：拡大・縮小
- 視点ボタン：正面／真上／横から／裏側／塔に接近
- 時間帯ボタン：昼／夕方／夜（夜は窓に明かりが灯ります）
- 自動回転のオン／オフ、視点リセット

ページスクロールで回転する方式ではありません。画面全体が3D表示で、タッチ操作がそのまま視点移動になります。

## ファイル構成

- `index.html` … ページ本体
- `style.css` … ページの見た目
- `script.js` … 3Dシーン（城・岩山・地面・木々）、質感の生成、視点と時間帯の制御

石壁・スレート屋根・岩肌・草地の質感は、外部画像を使わずプログラムで生成しています。
3Dライブラリは Three.js（CDN）を読み込んで使います。

## 周囲の地形について

城の周りは湖ではなく、草地の地面が広がる地形にしています。岩山のふもとには階段道と小屋があります。
